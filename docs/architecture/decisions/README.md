# Architecture decision records

This index lists the accepted and proposed architecture decisions. Each record gives its rationale, acceptance evidence and revisit conditions. Record the accepting authority and date; research alone cannot accept a decision. ADR numbers are stable identifiers, not a sequence. Proposed status records authority/acceptance; it does not mean that no related code exists. The [implementation plan](../../planning/implementation-plan.md#status) and [current architecture](../overview.md) identify implemented local behavior separately.
